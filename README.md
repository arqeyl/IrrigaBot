An irrigation system made using Arduino components and a mobile application developed on MIT App Inventor.

Below is a YouTube video on how to assemble the Arduino components and a demonstration of the mobile application:

https://www.youtube.com/watch?v=Sm5TvAR84Lo

----

## Getting Started

**1. Setup Arduino**

Components needed:
```
1. Arduino Uno x1
2. 40-way 20cm Dupont Jumper Wire M-M x19
3. 40-way 20cm Dupont Jumper Wire M-F x9
4. Battery AA x4
5. 5V Relay Module x1
6. Bluetooth Module x1
7. Vase x1
8. Pipe x1
9. Water Tank x1
10. USB Cable x1
11. Moisture Sensor x1
12. Water Pump x1
```
